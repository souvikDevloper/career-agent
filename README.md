# Career Agent

**A voice- and chat-driven job-search agent that finds openings, explains fit with evidence, prepares truthful applications, submits them under rules you set, and follows replies into assessments and interviews. Built serverless on AWS.**

> Status: under active development for the WeMakeDevs *First Commit* AWS hackathon (Ship It track). Live URL and demo video are added below once deployed.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the design.
